# Infinimesh

Cloud-native IoT stack. Apache-2.0.

| Repo | What it is |
|---|---|
| [core](https://github.com/infinimesh/core) | Device registry, shadow, MQTT bridge, APIs, console |
| [proto](https://github.com/infinimesh/proto) | gRPC, Connect, and OpenAPI |
| [inf-cli](https://github.com/infinimesh/inf-cli) | `inf` command |
| [operator](https://github.com/infinimesh/platform-operator) | Kubernetes operator |
| [k8s](https://github.com/infinimesh/k8s) | Cluster install recipes |
| [website](https://github.com/infinimesh/website) | Static site |
| [addon-sdk](https://github.com/infinimesh/addon-sdk) | Shared addon client |
| [addon-redis-stream](https://github.com/infinimesh/addon-redis-stream) | API to Redis stream |
| [addon-elasticsearch](https://github.com/infinimesh/addon-elasticsearch) | Redis stream to Elasticsearch |
| [addon-snowflake](https://github.com/infinimesh/addon-snowflake) | Redis stream to Snowflake |
| [addon-sap-hana](https://github.com/infinimesh/addon-sap-hana) | Redis stream to SAP HANA |
| [addon-timeseries](https://github.com/infinimesh/addon-timeseries) | API to RedisTimeSeries |
| [addon-cloud-connect](https://github.com/infinimesh/addon-cloud-connect) | API to S3, GCS, and Azure Blob |
